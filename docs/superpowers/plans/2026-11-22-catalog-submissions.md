# Приём предложений в каталог

**Цель.** Принимать предложенные карточки через приватную Google Таблицу. Модератор проверяет заявки перед отдельной публикацией офлайн-каталога.

1. Реализовать и протестировать приёмник Google Apps Script. Проверять код приглашения, схему карточки и уникальность идентификатора запроса. Фиксировать статус `pending` на сервере и записывать через Sheets API в режиме `RAW`.
2. Добавить отправку из Android с предпросмотром карточки. Коды приглашения вводятся пользователем. Не включать в запрос профиль, дневник, замеры или фотографии. Сохранять идентификатор при повторной попытке. Тестировать ошибки сети и повторную отправку.
3. Подготовить импорт одобренных строк с проверкой происхождения, дублей и единиц. Публиковать версионированный файл отдельно от APK. Android проверяет файл перед заменой предыдущей версии и сохраняет офлайн-доступ.
4. Развернуть приёмник в аккаунте владельца таблицы и проверить полную цепочку на вымышленной записи. Публикация одобренной заявки требует отдельного действия модератора.
