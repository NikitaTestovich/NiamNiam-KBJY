# Тестирование, CI/CD и обновления

**Цель:** обеспечить тесты исполняемого кода, измерение покрытия, проверки изменений в GitHub и обновление приложения через интернет с сохранением данных.

**Требования пользователя:** использование семьёй и знакомыми; приватный репозиторий без чувствительных данных; подключённый телефон доступен для тестов; APK дублируется в корень проекта. GitHub-публикация отложена до готовности 0.5.

## Выполнение

- [ ] Изучить обновления бюджетного приложения и определить применимый канал получения метаданных/APK. Убедиться, что приватные токены не попадают в приложение.
- [ ] Написать тесты сравнения версии, проверки метаданных и безопасного получения обновления; реализовать проверяемый сценарий с обработкой сетевых ошибок. Установка — через системное подтверждение Android, одинаковый package/signing key, возрастающий versionCode.
- [ ] Подключить измерение покрытия unit-кода и GitHub Actions для pull request и push. Проверки: unit, отчёт покрытия, lint, APK, Android-тесты; сохранять отчёты и APK как артефакты.
- [ ] Для выпуска подготовить CD с отдельным этапом подписи/публикации, недоступным при неуспехе тестов; секреты только в защищённых настройках GitHub. Публикацию не выполнять до выполнения разрешённых условий.
- [ ] Проверить подключённый телефон и выполнить тесты с отдельным package, сохранив личное приложение и его данные.
- [ ] Повторно проверить изменённые сценарии и состав APK, скопировать итоговую пользовательскую сборку в корень с проверкой SHA-256.

## Ограничения приёмки

Работающий локально workflow ещё не доказывает успешный запуск в GitHub и запрет слияния: потребуются отправка кода и настройки защиты ветки. Отчёт покрытия не заменяет проверки поведения. Удалённый канал обновлений и постоянная подпись должны быть настроены до проверки обновления установленного приложения от начала до конца.
