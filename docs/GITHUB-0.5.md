## Releases

**Тег** `v0.5`

**Заголовок** `NiamNiam KBJY 0.5 для Android`

**Описание релиза**

> Первая версия личного дневника питания для Android.
>
> - Дневник калорий и БЖУ с дневными целями, изменяемыми порциями и историей приёмов пищи.
> - Офлайн-каталог продуктов и готовых блюд, ручной ввод и расчёт домашних рецептов по ингредиентам.
> - Поиск по штрихкоду и QR-коду, чтение КБЖУ с этикетки и правка распознанных значений перед сохранением.
> - Учёт выпитых напитков, график веса и отчёты XLSX за неделю, месяц или всё время.
> - Русский и английский интерфейс, три темы оформления.
>
> Android 8.0 и новее. Дневник, каталог и сканер работают без интернета. Для установки скачайте `niamniam-kbjy-vc1.apk`. Ему соответствует контрольная сумма в `SHA256SUMS`.

## Actions

`Android verification` проверяет файлы репозитория, запускает тесты, собирает APK и сохраняет отчёты покрытия. `Publish Android release` подписывает проверенный APK и публикует версию по ручному запуску. Вкладка отображает запуски GitHub Actions после отправки workflow. [Описание CI/CD](CI-CD.md)
