# NiamNiam KBJY

Первая запланированная версия Android — **0.5**. Разработка и приёмка этой версии проходят локально. Первая отправка на GitHub запланирована после проверки APK и состава публикуемых файлов.

Личный офлайн-дневник питания для Android. В план первой версии входят подсчёт калорий и БЖУ, каталог продуктов и рецептов, сканирование этикеток, учёт жидкости и веса, а также отчёты в Excel.

В репозитории хранятся документация, эскизы, исходный код и разрешённые к распространению данные каталога. Для примеров и тестов используются вымышленные записи. Личные дневники, замеры, фото этикеток пользователей, выгрузки и резервные копии должны оставаться вне репозитория.

- [Спецификация](docs/superpowers/specs/2026-11-20-calorie-diary-design.md) — продуктовые сценарии, расчёты, ограничения и утверждённые требования.
- [Сценарии приёмки](docs/superpowers/specs/2026-11-20-calorie-diary-acceptance.md) — примеры для проверки реализации.
- [Эскизы экрана «Сегодня»](design/today-options.html) — выбран вариант А с кольцом.
- `android/` — каталог будущих исходников Android.
- `data/` — каталог будущих исходных наборов продуктов и тестовых данных.

Спецификация утверждена 20 ноября 2026 года. [План разработки для Superpowers](docs/superpowers/plans/2026-11-20-calorie-diary.md).
